# Clara & John Wedding Invitation Link Builder

This is a static website. It includes the invitation artwork and envelope reference image, an envelope-opening interaction, and a small link creator.

## Publish it once
1. Create a GitHub repository (for example `wedding-invitation`).
2. Upload `index.html` and the `assets` folder to the repository root.
3. In the repository, open **Settings → Pages** and enable deployment from the `main` branch / root folder.
4. Once GitHub Pages gives you the site URL, open that URL. Use **Create / share link** and **Generate invitation link**.
5. Copy the generated invitation URL and add it to your Joy wedding website.

The generated link is made by this invitation website, not by the GitHub repository interface. It stores the welcome message and button label in the URL fragment, so no database or guest list is needed.

Note: this is a tailored starter version. The envelope is a recreated CSS interaction using your supplied reference screenshot; it does not reproduce Paperless Post’s exact proprietary animation.
